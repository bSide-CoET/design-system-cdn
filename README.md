# bSide Design System · CDN

Built standalone bundle of `@bside-coet/design-system` for plain HTML pages, served by GitHub Pages.
Each release of the design system publishes `v<version>/` and refreshes `latest/`. Never edited by hand.

```html
<link rel="stylesheet" href="https://bside-coet.github.io/design-system-cdn/latest/bside-ds.css">
<script src="https://bside-coet.github.io/design-system-cdn/latest/bside-ds.js"></script>
```

Pin a version in place of `latest` (e.g. `v1.0.0-beta.35`) for pages that must not change. Each folder's
`index.html` is a working example.
